# Public operational-policy fixture for the P3 tests

The original operational note contains private authorisations and billing observations and is withheld. This public replacement is an inert input to the synthetic plan-building tests: their fingerprint function hashes this path, but does not interpret its prose.

The historical control used a local, locked journal with a USD 150 daily ceiling in `America/Sao_Paulo`, while preserving each experiment's smaller cap. Pending and uncertain reservations continued to count; midnight did not release them. The journal was not an account-wide provider billing limit.

This file is a public test fixture, not the historical note. Its hash intentionally differs from that note and from the corresponding entry in sealed experiment plans. Do not use a plan regenerated with this fixture as an authorised replay or as evidence of the historical financial admission. The archived plans and traces in the versioned deposits remain the research record.
